## 4. Feature Engineering и ML Pipeline

Использован **полный объектно-ориентированный Pipeline** `pyspark.ml`:

- `StringIndexer` + `OneHotEncoder` — для `time_of_day`  
- `VectorAssembler` + `StandardScaler` — сборка вектора `features`  
- Модель: `RandomForestClassifier` (numTrees=50, maxDepth=10)

**Этапы Pipeline:**
1. StringIndexer (label)  
2. StringIndexer + OneHotEncoder (time_of_day)  
3. VectorAssembler  
4. StandardScaler  
5. RandomForestClassifier
